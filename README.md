# Flight Controller | فلایت کنترلر

## 🇬🇧 English

### Overview

This repository contains the hardware design files of a custom-designed flight controller intended for Unmanned Aerial Vehicle (UAV) applications.

The project is being developed to create a dedicated flight control platform, including custom PCB hardware and embedded firmware.

The hardware design has been completed and tested. Firmware development is currently in progress, and the project is not yet considered complete.

### Project Status

- [x] Hardware design
- [x] Schematic design in Altium Designer
- [x] PCB layout
- [x] Initial hardware testing
- [ ] Firmware development
- [ ] Flight control algorithm implementation and tuning
- [ ] System integration and validation
- [ ] Flight testing

*Note: The checklist reflects the current development status and will be updated as the project progresses.*

### Hardware Design

The hardware design files are developed using **Altium Designer**.

This repository is intended to document the hardware design and track the ongoing development of the flight controller.

### Repository Contents

- **Schematic:** Circuit schematic files.
- **PCB:** Printed Circuit Board design files.
- **Documentation:** Technical documentation and project updates, as they become available.

*The exact contents may evolve throughout development.*

### Development Roadmap

The next development stages focus on:

1. Firmware development and peripheral configuration.
2. Sensor integration and data acquisition.
3. Flight control algorithm implementation.
4. Controller tuning and system validation.
5. Controlled flight testing.

### Disclaimer

This project is under active development. Although the hardware has undergone initial testing, the complete flight control system has not yet been fully validated.

This flight controller should not be considered flight-ready until firmware development, system integration, and appropriate safety testing have been completed.

### Contributions

Suggestions, technical discussions, and constructive feedback are welcome as the project evolves.
